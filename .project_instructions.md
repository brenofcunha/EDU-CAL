## EduCalc — Plataforma de Estudo de Cálculo

### Stack
- Next.js 16 (App Router) + TypeScript + Tailwind CSS + shadcn/ui
- Supabase JS client (@supabase/ssr) para auth e banco — NÃO usa Prisma nem NextAuth
- KaTeX + react-markdown + remark-math + rehype-katex para fórmulas
- Framer Motion para animações

### Design
- Tema: indigo/azul educacional (primary: 239 84% 67%)
- Suporte dark/light mode via next-themes
- Interface em Português (Brasil)
- Ícones: lucide-react

### Autenticação
- Supabase Auth (email/senha) via @supabase/ssr cookies
- proxy.ts para refresh de sessão e proteção de rotas
- Rotas protegidas: /dashboard, /pasta, /perfil, /forum/novo, /admin/*
- Admin: conta com email prefix 'brenofcunha' recebe role='admin' via trigger SQL

### Banco de Dados
- Schema completo em supabase/schema.sql (para rodar no SQL Editor do Supabase)
- Banco começa VAZIO — sem seed
- RLS habilitado em todas as tabelas
- Variáveis via .env.example (usuário preenche depois)

### Estrutura de Rotas
- Públicas: /, /trilhas, /trilhas/[track], /forum, /forum/[id], /login, /cadastro, /esqueci-senha
- Autenticadas (grupo (authenticated)): /dashboard, /pasta, /perfil, /admin/*
- Admin: /admin, /admin/usuarios, /admin/conteudo, /admin/forum, /admin/tags, /admin/logs

### Regras Importantes
- Não usar Prisma — Supabase JS client direto
- App não crasha sem credenciais Supabase (graceful degradation)
- MarkdownRenderer usa dynamic import com ssr:false
